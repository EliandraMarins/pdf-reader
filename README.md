# Invoice Reader in Python 🧾

A Python-based tool designed to extract and manage key information from invoices efficiently. This project reads invoice files and retrieves essential details such as the invoice number, file name, and date, streamlining invoice processing and data management workflows.

## Features

- Extracts invoice numbers automatically

- Captures invoice file names for easy reference

- Reads and stores invoice dates

- Lightweight and easy to integrate into existing Python projects

## Technologies

- Python 3.12

- Libraries: openpyxl, pdfplumber

## Use Cases

- Automating invoice data extraction for accounting

- Organizing invoices by date or number

- Preparing data for financial reporting or analytics
